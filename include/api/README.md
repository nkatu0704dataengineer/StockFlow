# API Integrations Module

This module contains client integrations for external stock market data provider APIs:
- `nasdaq.py`: Integration client for NASDAQ API.
- `yahoo.py`: Integration client for Yahoo Finance API.
- `polygon.py`: Integration client for Polygon.io API.
- `finnhub.py`: Integration client for Finnhub API.
- `alpha_vantage.py`: Integration client for Alpha Vantage API.
